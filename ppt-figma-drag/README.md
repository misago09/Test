# PPT Figma Drag

파워포인트의 마우스 드래그 선택을 **피그마처럼** 바꿔주는 윈도우 트레이 프로그램입니다.

- **파워포인트 기본 동작**: 드래그 사각형에 **완전히 포함된** 도형만 선택됨
- **이 프로그램 실행 후**: 피그마처럼 드래그 사각형에 **걸치기만 해도** 선택됨

AutoHotkey를 쓰지 않으며, 별도 런타임 설치도 필요 없습니다 (.NET Framework 4.8 —
Windows 10/11에 기본 내장).

## 왜 안 버벅거리나

흔한 트레이 앱 구현(특히 Python 계열)은 전역 마우스 훅 콜백 안에서 COM 호출이나
그리기 같은 무거운 작업을 해서 **시스템 전체 마우스가 밀리는** 렉이 생깁니다.
이 프로그램은 구조적으로 그 문제를 피합니다.

1. **훅 콜백은 사실상 아무 일도 안 함** — 왼쪽 버튼 다운/업 좌표를 큐에 넣는 것이
   전부이고, 마우스 이동 이벤트는 비교 한 번 후 즉시 통과시킵니다. (COM 호출 0회,
   그리기 0회)
2. **드래그 중에도 아무 일도 안 함** — 드래그 사각형(러버밴드)은 파워포인트가
   원래 그리던 것을 그대로 사용합니다.
3. **마우스를 뗀 순간에만** 별도 워커 스레드에서 PowerPoint COM으로 "걸친 도형"을
   계산해 선택을 확장합니다. 마우스 입력 경로와 완전히 분리되어 있어 지연이
   생길 수가 없습니다.

## 빌드 방법

### 방법 1 — 아무것도 설치하지 않고 (권장)

저장소를 받은 뒤 `ppt-figma-drag` 폴더에서 **`build.cmd`를 더블클릭**하면
윈도우에 내장된 C# 컴파일러로 `PptFigmaDrag.exe`가 만들어집니다.

### 방법 2 — .NET SDK가 있다면

```
cd ppt-figma-drag
dotnet build -c Release
```

## 사용 방법

1. `PptFigmaDrag.exe` 실행 → 작업 표시줄 트레이에 파란 점선 사각형 아이콘이 생깁니다.
2. 파워포인트에서 빈 캔버스를 드래그하면, 사각형에 **걸친 도형까지 전부** 선택됩니다.
3. `Shift` + 드래그: 기존 선택에 **추가** (피그마와 동일)
4. 트레이 아이콘 우클릭:
   - **사용** 체크 해제 → 파워포인트 기본 동작으로 복귀 (아이콘 더블클릭으로도 토글)
   - **Windows 시작 시 자동 실행** 등록/해제
   - **종료**

## 동작 원리 (요약)

- `WH_MOUSE_LL` 전역 훅으로 왼쪽 버튼 다운/업만 감지 (이벤트를 가로채지 않고 통과만 시킴)
- 버튼 다운 시 워커 스레드가 COM(Late binding)으로 확인:
  - 활성 창이 파워포인트 편집 화면(기본 보기)인지
  - 드래그 시작점이 슬라이드 캔버스의 빈 영역인지 (도형 위·크기조절 핸들 근처·리본·썸네일이면 개입 안 함)
  - 현재 슬라이드의 도형 위치·회전을 스냅샷 (회전된 도형은 AABB로 계산)
- 버튼 업 시: 드래그 사각형을 슬라이드 좌표로 환산 → 걸친 도형들을 `ShapeRange.Select()`
- 좌표 변환은 `PointsToScreenPixelsX/Y`를 매번 새로 샘플링하므로 줌·스크롤·자동
  스크롤에도 정확합니다. Per-Monitor V2 DPI 인식이라 고해상도/다중 모니터에서도 좌표가 맞습니다.

## 개입하지 않는 경우 (안전 장치)

- 도형 위에서 시작한 드래그 (이동/복사), 선택된 도형의 핸들 근처 (크기조절/회전)
- `Ctrl`/`Alt`를 누른 드래그 (파워포인트 고유 기능 유지)
- 6px 미만의 움직임 (클릭으로 간주)
- 슬라이드 쇼·여러 슬라이드 보기 등 기본 편집 화면이 아닌 경우
- 리본, 슬라이드 썸네일, 노트 영역에서 시작한 드래그
- 내용이 없는 자리표시자("제목을 추가하려면 클릭")는 피그마처럼 선택 대상에서 제외

## 알려진 제한

- 드래그 도중 `ESC`로 취소한 경우에도 버튼을 떼면 선택이 적용될 수 있습니다.
- 회전된 도형은 실제 외곽선이 아니라 회전 반영 바운딩 박스 기준으로 판정합니다.
- 도형이 수백 개인 슬라이드에서는 버튼을 뗀 뒤 선택 확장까지 0.1~0.5초 정도
  걸릴 수 있습니다(마우스 자체는 밀리지 않음).
